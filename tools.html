The #1 thing people ask me

Which AI tool should you actually use?

This was the single most-requested help topic when I asked people what they needed most, ahead of prompting tips or understanding the jargon. So here's my honest answer, not a feature chart with forty ticks and crosses.

What are you actually trying to do?

Answer a couple of quick questions and I'll point you at the right one, or skip it and scroll through all six yourself.

Everyday questions

Use ChatGPT

It's the one most people land on first, and a genuinely solid all-rounder for quick questions and everyday writing. It's also my go-to recommendation for image generation, and the safe default if you only ever install one thing.

Ongoing projects

Use Claude

This is my own daily tool, and specifically where it wins: organising a project, coming back to something across several sessions, or working through documents. If ChatGPT is a quick chat, this is more like a colleague who remembers the project.

Lives in Google

Use Gemini

Its real strength is how tightly it sits inside Google's own apps, meeting notes, your inbox, your calendar. If your life already runs on Google, this is the one that plugs straight in.

No-code building

Use Lovable

If you want an actual app, website, or tracker built and you don't want to write code, this is built exactly for that. Describe what you want in plain English and it builds a working version.

Your own documents

Use NotebookLM

Upload your own files, research, notes, whatever, and it becomes an expert on exactly that content, with sources you can check. Genuinely underrated for anything research-heavy.

Web research, cited

Use Perplexity

It searches the web and reads the results for you, then gives you an actual answer with the sources clickable underneath so you can check it yourself. Better than a normal search engine for anything where you'd otherwise open ten tabs.

Microsoft 365

Use Copilot

If your work already runs on Word, Excel and Outlook, Copilot is the one that's already sitting inside them. Less exciting than the others, genuinely useful if that's your world.

My honest take: don't try to learn all of these at once. Pick the one that matches what you actually spend your day doing, and get properly comfortable with it before you add a second one.

Want to go further?

These two are a level up from everything else on this page, proper coding tools rather than something you need on day one. Worth knowing about once the basics feel easy and you're curious what's next, not before.

Advanced

Use Cursor

A proper code editor with AI built in, not a chat window bolted onto the side. If you've built something in Lovable and you're ready to actually open and understand the code behind it, this is usually where people go next.

Advanced

Use Claude Code

The command-line version of Claude, built for writing and shipping real code rather than chatting about it. This entire site was built with it, sat inside the folder on my computer making the actual file changes. It's usually covered by a normal Claude subscription, no separate sign-up.
